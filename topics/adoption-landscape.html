增长路径

开源首日 9,000 Stars → 3 天 60,000 → 2 周 190,000 → 60 天 250,000。全有机增长，未上线 Product Hunt，无 VC 推广。中国开发者社区在项目走红数天内即贡献了中文翻译、部署指南和教程。

社区活跃渠道包括 Discord 服务器（结构化管理）、X/Twitter @OpenClawCommunity、ClawCon 2026 技术大会。项目以每周多版本的频率持续迭代，当前版本 2026.3.14。

C端：个人 AI 助手 — 最核心的定位

OpenClaw 的产品定位是 "Personal AI Assistant"，C 端个人用户是其核心用户群。以下场景均来自官方 Showcase 和社区真实案例。

最热门

每日早报 / Daily Briefing

通过 Telegram/WhatsApp 推送个性化晨间摘要：天气、日历、任务、新闻、健康数据。替代 5-6 个 App 的信息聚合。

最热门

邮件自动化管理

社区案例：处理 15,000 封邮件，自动退订垃圾邮件、按紧急程度分类、起草回复。报告节省 78% 邮件处理时间。

最热门

智能家居控制

通过 Home Assistant 集成，自然语言控制 Philips Hue 灯光、Elgato 设备、恒温器等。社区项目 GoHome 提供 Nix + Grafana 完整方案。

增长中

购物 & 预订自动化

浏览器自动化完成 Tesco 超市周订单、Padel 球场预订、ParentPay 学校餐食预订。无需 API，纯浏览器控制。

增长中

开发者工具链

PR Review 结果推送 Telegram、Jira/Linear 集成、Codex 任务监控、iOS App 通过 Telegram 聊天完成 TestFlight 部署。

增长中

健康 & 量化自我

Oura 智能戒指数据集成，关联日历、健身计划、就医预约。个人 AI 健康助手。

垂直场景

金融与交易分析

浏览器自动化登录 TradingView、截图K线图、执行技术分析。自然语言查询消费记录。

垂直场景

硬件 IoT 控制

BambuLab 3D 打印机管理、Winix 空气净化器控制、Roborock 扫地机器人对话操控。

垂直场景

语言学习 & 知识管理

中文学习引擎（发音反馈）、WhatsApp 语音笔记转录索引、书签语义搜索。

C端核心价值

OpenClaw 的 C 端壁垒在于 22+ 消息渠道的统一接入。用户不需要离开自己习惯的 IM（WhatsApp / Telegram / iMessage），就能获得完整的 AI 助手能力。这是 ChatGPT 等云端 AI 做不到的。

B端：企业自动化 — 早期但增长快

B 端采纳集中在小团队 / 一人公司 / 自由职业者，尚未进入大型企业的正式 IT 采购流程。以下是已验证的商业场景。

☍
客服与支持
  • Slack 自动客服：监控公司 Slack 频道，自动回复 support 问题，转发通知至 Telegram。有案例报告 Agent 自主修复生产环境 bug。
  • 多语言支持：Broadcast Groups 允许同一消息触发多个 Agent，可实现英语/德语/西语并行响应。
  • 工单分级：连接 Slack/Discord/WebChat，从知识库匹配答案，按紧急程度分级上报。
⚙
销售与获客
  • AI SDR（Sales Development）：24/7 监控表单提交 → Lead 信息富化 → 个性化跟进邮件 → 写入 CRM。
  • 园艺公司案例：5 分钟内响应 leads，成交率提升 30%。
  • 一人公司收入：有用户报告使用 OpenClaw 3 周内创收 $14,700；另有人运营 $4,000/周 的自动化业务。
⚒
流程自动化
  • 客户 Onboarding：一条消息触发：创建文件夹 → 发邮件 → CRM 更新 → 日历邀请 → 权限配置，15 分钟完成。
  • 会计自动化：从邮件收集 PDF 发票，准备报税材料，月度记账自动化。
  • eBay 运营：发货日期跟踪、消息管理、预订管理。
❖
多 Agent 协作
  • Dream Team 架构：14+ Agent 在一个 Gateway 下，Opus 4.5 编排器分派任务给 Codex 执行者。包含完整的技术架构文档。
  • 代码审查团队：CodeReviewer + SecurityAuditor + TestGenerator + DocsChecker 并行处理同一 PR。
  • 零售数据分析：处理 29 家门店、40TB 数据的定价情报和商品匹配。

B端采纳瓶颈

B 端用户普遍是技术型创业者和自由职业者，而非 IT 部门通过正式流程引入。缺乏多租户、RBAC、审计日志、SLA 等企业级功能，是进入正式 B 端采购的最大障碍。参见 toB 技术分析。

G端：政府市场 — 当前为零

截至 2026 年 3 月，未发现任何政府部门部署 OpenClaw 的公开案例。这是多重因素共同导致的。

1
安全漏洞密集
  • CVE-2026-25253（CVSS 8.8）WebSocket Token 窃取，可远程执行命令
  • 42,000+ 暴露实例无认证运行
  • 820+ ClawHub 恶意 Skill，335 个属于 "ClawHavoc" 攻击活动
2
多机构安全警告
  • 中国 CERT："极弱的默认安全配置"
  • Microsoft：发布安全运行指南
  • Cisco："a security nightmare"
  • Kaspersky：默认配置 "unsafe for use"
  • Trend Micro：发布 CISO 安全分析报告
3
结构性障碍
  • 项目仅 ~4 个月历史，远未达到政府采购周期要求
  • 无等保测评、无安全评估报告、无算法备案
  • 无商业实体、无 SLA、无法签署政府合同
  • Prompt Injection 攻击面为架构性问题，非配置可解

安全成熟度：增长速度远超安全加固

OpenClaw 的安全问题并非设计意愿缺失——其代码中包含 7 层工具权限管道、Docker 沙箱、执行审批等机制。问题在于爆发式增长暴露了默认配置的脆弱性，大量非技术用户在未加固的情况下暴露在公网。

!
已知安全事件时间线
  • 2026-02 CVE-2026-25253：WebSocket Token 窃取漏洞（CVSS 8.8），攻击者可接管 Gateway 并远程执行任意命令。 CRITICAL
  • 2026-02 42K+ 暴露实例：安全研究人员发现超过 42,000 个 OpenClaw 实例无认证暴露在公网，可被任意访问。 HIGH
  • 2026-03 ClawHavoc 攻击：ClawHub 技能市场发现 820+ 恶意 Skill，其中 335 个属于名为 "ClawHavoc" 的协调攻击活动。类比 npm 供应链攻击。 HIGH
  • 2026-03 中国 CERT 通告：中国国家计算机网络应急技术处理协调中心（CERT）发布安全警告，指出 OpenClaw 默认安全配置极弱。 MED
  • Prompt Injection：Agent 从邮件、网页等外部内容中摄取文本并调用工具执行，天然存在提示注入攻击面。此为 AI Agent 架构的固有问题。 ONGOING
对 SensePedia 的启示

OpenClaw 的安全教训值得所有 AI Agent 平台参考：1) 默认配置必须安全（secure by default），不能依赖用户手动加固；2) 技能市场需要审核机制和代码签名；3) Agent 从外部内容摄取信息时必须有隔离沙箱，防止 Prompt Injection 跨越信任边界。

结论与启示

1
市场信号明确
  • 250K Stars 验证了 "把 AI 接入已有消息渠道" 这一产品方向的真实需求
  • C 端个人 AI 助手已被充分验证，但 B 端和 G 端存在巨大的产品化空白
  • 企业客户需要的不是 "更好的 OpenClaw"，而是在这个方向上做出完全不同安全等级的产品
2
SensePedia 的机会窗口
  • OpenClaw 在 B 端和 G 端的空白，恰恰是 SensePedia Agent Platform 的目标市场
  • 可借鉴 OpenClaw 验证过的产品模式（多渠道接入、Skill 生态、多 Agent 协作），在安全合规和企业级能力上做差异化
  • OpenClaw 的安全事件为竞品提供了反面教材——"Secure by Default" 应是产品核心卖点
一句话总结

OpenClaw 证明了需求，暴露了风险，留下了空间。C 端已被占领，B/G 端大门敞开——前提是你能交付企业级安全、合规和运维能力。
